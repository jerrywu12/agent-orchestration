# Decisions
Use standard Node metadata/OS APIs and asynchronous execFile for a fixed ps command, without a shell or user-supplied arguments. Node documents the asynchronous child-process API and fs file/directory APIs: https://nodejs.org/docs/latest-v22.x/api/child_process.html and https://nodejs.org/docs/latest-v22.x/api/fs.html. No CLI --version probes: installed agents can authenticate/update or run expensive initialization even on apparent inspection commands. Python package metadata is read from bounded dist-info METADATA; no package import or setup invocation. Installed and declared states remain separate.

Existing repo uses React19, native Node HTTP, SQLite records and project-local Playwright; reuse them. Generic Node/Python comm values cannot prove which interpreter-hosted agent is running. Preserve that uncertainty and use separately labeled fixed service health probes. Prior DeerFlow advice request remains unavailable with ReadBeforeWriteConfig.elide_blocked_payloads; local code/fixture/browser verification and independent in-task review are authoritative.
